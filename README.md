# 🎲 Dice Roll Game in Java

## 📌 Project Description
The Dice Roll Game is a simple Java-based application that simulates rolling a dice. Whenever the user rolls the dice, the program generates a random number between 1 and 6.

This project is developed using Java programming language and helps beginners understand random number generation and basic Java concepts.

## 🚀 Features
- Generates random numbers from 1 to 6.
- Simulates a real dice roll.
- Allows users to roll the dice multiple times.
- Simple and beginner-friendly Java program.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Concepts:** Random Class, Loops, Conditional Statements, User Input.

## 💻 How to Run the Project

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project in VS Code, Eclipse, or IntelliJ IDEA.
4. Compile the Java program:

```bash
javac DiceRoll.java
```

5. Run the program:

```bash
java DiceRoll
```
